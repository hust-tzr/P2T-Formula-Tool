
# 公式识别工具 v1.0

基于 `pix2text` 的数学公式截图识别应用，支持将公式图片转换为 Markdown 格式。

## ✨ 主要功能

### 第1阶段（已完成）
- ✅ **多种输入方式**
  - 📁 打开本地图片文件（PNG、JPG、BMP 等）
  - 📋 从系统剪贴板粘贴截图
  - 🎯 支持拖放图片到应用窗口

- ✅ **公式识别**
  - 使用 pix2text 深度学习模型识别数学公式
  - 输出 LaTeX 格式的识别结果
  - 智能错误处理和超时机制

- ✅ **Markdown 转换**
  - 自动选择行内公式 `$...$` 或块级公式 `$$...$$`
  - 可配置的输出格式
  - LaTeX 语法验证（基础检查）

- ✅ **导出功能**
  - 保存为 Markdown 文件
  - 复制结果到剪贴板
  - 支持手动编辑识别结果

### 第2阶段（计划）
- 🔜 批量处理多个图片
- 🔜 公式编辑和验证
- 🔜 导出为 PDF 和 Word 格式

## 🚀 快速开始

### 环境要求

- Python 3.10+
- Conda 环境 `p2t` 已配置
- 已安装依赖：PyQt6、pix2text、Pillow、markdown2、python-docx、reportlab

### 安装依赖（如需重新安装）

```bash
# 激活p2t环境
conda activate p2t

# 进入项目目录
cd g:\tzr\pix2text

# 安装依赖
pip install PyQt6 markdown2 python-docx reportlab
```

### 运行应用

**方式1：双击启动脚本（推荐）**
```
双击 run.bat 文件
```

**方式2：命令行启动**
```bash
conda activate p2t
cd g:\tzr\pix2text
python app.py
```

**方式3：在 VS Code 中运行**
- 打开 `app.py`
- 按 `Ctrl+F5` 或点击右上角的运行按钮

## 📖 使用步骤

1. **加载图片**
   - 点击 "📁 打开文件" 选择图片文件，或
   - 点击 "📋 粘贴截图" 从剪贴板粘贴，或
   - 直接拖放图片到预览区

2. **选择公式格式**（可选）
   - "自动选择"：根据公式复杂度自动选择
   - "行内公式 $...$"：用于短公式
   - "块级公式 $$...$$"：用于复杂公式

3. **识别公式**
   - 点击 "🔍 识别公式" 按钮
   - 等待识别完成（首次运行会加载模型，需要30-60秒）
   - 识别结果显示在右侧文本框

4. **处理结果**
   - "📋 复制结果" - 复制到剪贴板
   - "💾 保存为Markdown" - 保存到文件
   - 可手动编辑识别结果（双击文本框后编辑）

5. **清除并重新识别**
   - 点击 "🗑️ 清除" 删除当前图片

## 📋 已知限制

1. **首次启动需要加载模型**
   - pix2text 第一次使用时需要下载和加载深度学习模型
   - 预计需要30-60秒，取决于网络速度
   - 后续启动会快得多（模型已缓存）

2. **识别准确度**
   - 识别结果的质量取决于输入图片的质量
   - 清晰的黑白公式图片识别效果最好
   - 复杂的多行公式可能需要手动调整

3. **Windows使用**
   - 当前只在 Windows 系统上测试
   - Linux/Mac 用户可能需要调整部分代码（特别是剪贴板功能）

## 🐛 故障排除

### 问题1：应用启动时出现 "ModuleNotFoundError"
**解决方案：**
```bash
conda activate p2t
pip install --upgrade PyQt6 pix2text markdown2 python-docx reportlab
```

### 问题2：模型加载失败
**可能原因：**
- 网络连接问题（模型需要从网络下载）
- 磁盘空间不足
- Python 环境配置错误

**解决方案：**
- 检查网络连接
- 清理磁盘，确保至少有2GB可用空间
- 尝试重新启动应用

### 问题3：粘贴截图不工作
**解决方案：**
- 确保先复制图片到剪贴板（Win+Shift+S 截图后自动复制）
- 确保 PIL/Pillow 已正确安装

### 问题4：识别结果为空或错误
**可能原因：**
- 图片不清晰或不是数学公式
- 图片中包含较少的数学内容

**解决方案：**
- 使用更清晰的截图
- 确保图片只包含单个或少数几个公式
- 手动编辑识别结果后重新格式化
